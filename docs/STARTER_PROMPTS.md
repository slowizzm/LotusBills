# Starter Prompts

These prompts assume the ChatGPT Project has already loaded the repository instructions through `PROJECT_INSTRUCTIONS.md`.

## Review this month's bills

Review only the bills and workbook attached to this chat. Run the monthly review workflow. Reconcile totals, compare the available periods, identify material changes or anomalies, and rank recommendations. Cite each material finding to a bill page/section or workbook sheet/range.

## Audit my Excel tracker

Audit the attached Excel workbook without modifying it. Inspect formulas, dates, totals, joins, duplicates, missing values, source coverage, and formula errors. Separate confirmed defects from optional design improvements. Trace each finding to a sheet and cell/range. Recommend fixes but do not edit the workbook unless I approve them.

## Compare two statements

Compare only the two attached statements. Normalize for billing-period length and units where possible. Separate usage, rate, tax/fee, credit, and one-time effects. Explain any residual difference that cannot be isolated. Recommend human next steps only.

## Find savings

Use the attached bills and workbook to find supported savings opportunities. Exclude one-time charges and temporary credits from the recurring baseline. Rank opportunities by annual impact, effort, reversibility, and risk. Show all assumptions. Do not research live offers unless I ask.
